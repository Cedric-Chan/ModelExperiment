# Model Experiment — Web 原型

与 [Figma：Model-Experiment](https://www.figma.com/design/C15E8rRER0qSqYsQZgdVif/Model-Experiment) 一致的交互原型（React + Vite + Tailwind）。

## 运行

```bash
npm install
npm run dev
```

开发时 `base` 为 `/`；执行 `npm run build` 时使用 `/ModelExperiment/`，供 GitHub Pages 部署。

## 构建

```bash
npm run build
```

输出目录：`dist/`。
