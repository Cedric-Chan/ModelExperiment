# Model Experiment — Web prototype

Interactive prototype aligned with [Figma: Model-Experiment](https://www.figma.com/design/C15E8rRER0qSqYsQZgdVif/Model-Experiment) (React + Vite + Tailwind).

## Run locally

```bash
npm install
npm run dev
```

Dev server uses `base` `/`; `npm run build` uses `/ModelExperiment/` for GitHub Pages.

## Build

```bash
npm run build
```

Output: `dist/`.
