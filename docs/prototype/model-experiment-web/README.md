# Model Experiment — Web prototype

**验收基准**：以本仓库 **`model-experiment-web` 实现**为交互与视觉验收基准；[Figma: Model-Experiment](https://www.figma.com/design/C15E8rRER0qSqYsQZgdVif/Model-Experiment) 为初次设计迁移原本与风格参考，**逻辑与布局以当前代码为准**。

React + Vite + Tailwind。

## Run locally

```bash
npm install
npm run dev
```

Dev server uses `base` `/`; `npm run build` uses `/ModelExperiment/` for GitHub Pages.

## Build

```bash
npm run build
```

Output: `dist/`.
